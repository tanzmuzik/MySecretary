🔔 うるさいよね！？通知

オフィスの騒音を共有するLAN通知アプリ

📥 ダウンロード (Windows版)

最新版: v1.0.0 | ファイルサイズ: 約5MB

🎯 概要

「うるさいよね！？通知」は、オフィスやチーム内で騒音が気になったときに、 ワンクリックで同じネットワーク上のメンバーに通知を送れる軽量デスクトップアプリです。 直接注意するのは気まずい…そんな時に、さりげなく気持ちを伝えられます。

✨ 主な機能

  • ワンクリック送信
    ボタン1つで「うるさいよね！？」メッセージを同じLAN内の全員に送信
  • デスクトップ通知
    画面全体のランダムな位置に吹き出しが表示され、誰でも気づきやすい
  • システムトレイ常駐
    タスクトレイに常駐し、アイコンクリックですぐに送信可能
  • 効果音機能
    送信時・受信時に効果音が鳴り、ON/OFF切り替え可能
  • 匿名送信
    誰が送ったかは表示されないので、気軽に使える
  • 設定不要
    起動するだけで自動的にネットワークを検出、面倒な設定は一切不要

💻 動作環境

対応OS

  • Windows 10 (64bit) 以降
  • Windows 11

ネットワーク要件

  • 同じLAN（ローカルエリアネットワーク）に接続されていること
  • UDPポート 5555 が使用可能であること
  • ファイアウォールでUDPブロードキャストが許可されていること

その他

  • インストール不要（実行ファイルを起動するだけ）
  • インターネット接続は不要

📖 使い方

  1. ダウンロードした実行ファイル (.exe) をダブルクリックで起動
  2. アプリが自動的にネットワークを検出し、準備完了
  3. 「うるさいよね！？を送信」ボタンをクリックするか、タスクトレイアイコンを左クリック
  4. 同じネットワーク上の全てのPCに通知が表示されます
💡 ヒント:
  • ×ボタンを押すとウィンドウが非表示になり、タスクトレイに常駐します
  • タスクトレイアイコンを右クリック → 「設定を開く」で再びウィンドウを表示
  • 効果音は設定パネルから ON/OFF 切り替え可能

🔒 プライバシーとセキュリティ

  • 完全ローカル動作
    インターネットへの通信は一切行いません
  • データ収集なし
    個人情報や使用統計の収集は行いません
  • オープンソース
    ソースコードは GitHub で公開されています

❓ FAQ（よくある質問）

Q: インストールは必要ですか？

A: いいえ、実行ファイルをダブルクリックするだけで使えます。

Q: 他のネットワークの人にも届きますか？

A: いいえ、同じLAN内のPCにのみ届きます。インターネット越しには届きません。

Q: 誰が送ったかわかりますか？

A: いいえ、送信者は表示されません。匿名で使えます。

Q: ファイアウォールの設定は必要ですか？

A: 初回起動時にWindowsファイアウォールの許可ダイアログが表示される場合があります。「アクセスを許可する」を選択してください。

Q: 複数のPCで同時に使えますか？

A: はい、同じネットワーク上で何台でも同時に使用できます。
