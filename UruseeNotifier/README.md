# 🔔 UruseeNotifier（うるせぇ通知）

Windows 向けの軽量デスクトップアプリ。UDP ブロードキャストで「うるせぇ！」を共有できます。

## 概要

同じネットワーク上の複数の PC で「うるせぇ！」を送り合える楽しい通知アプリです。
IP Messenger 方式の UDP ブロードキャストを使用して、匿名でメッセージを送受信します。

## 主な機能

### 基本機能
- **タスクトレイ常駐**: 起動後はタスクトレイに常駐
- **ワンクリック送信**: ボタンクリックで「うるせぇ！」を UDP ブロードキャスト
- **吹き出し表示**: 受信時に画面のランダム位置に吹き出しを 3 秒間表示
- **ランダム絵文字**: 💢🔔😤🗣️💔 の 5 種類からランダムに表示
- **効果音**: 送信時/受信時に異なる効果音を再生（ON/OFF 可能）

### UDP ブロードキャスト
- **ポート**: 5555 (UDP)
- **ブロードキャスト対象**: ローカルサブネット（自動検出）
- **サブネットマスク**: 255.255.255.0 を想定
- **匿名送信**: 送信者のマシン名は表示されません

### パケット仕様
```json
{
  "type": "uresee",
  "timestamp": 1234567890,
  "machine_id": "PC-001"
}
```

### ログ機能
- 今日の送信回数を表示
- 設定パネルから確認可能

## 技術スタック

- **フレームワーク**: Tauri 2.0
- **フロントエンド**: React + TypeScript + Vite
- **バックエンド**: Rust
- **通信**: UDP ブロードキャスト
- **ターゲット**: Windows のみ

## 開発環境のセットアップ

### 必要なツール

1. **Node.js** (v18 以降)
2. **Rust** (最新版)
   - https://www.rust-lang.org/tools/install
3. **Visual Studio Build Tools** (Windows)
   - C++ ビルドツールをインストール

### インストール手順

```bash
# 依存関係のインストール
npm install

# 開発モードで起動
npm run tauri dev
```

## ビルド方法

### Windows 向け exe ビルド

```bash
# プロダクションビルド
npm run tauri build
```

ビルド後、以下のディレクトリに exe ファイルが生成されます：

```
src-tauri/target/release/UruseeNotifier.exe
```

### インストーラー作成

Tauri は自動的に以下のインストーラーも生成します：

- **MSI インストーラー**: `src-tauri/target/release/bundle/msi/`
- **NSIS インストーラー**: `src-tauri/target/release/bundle/nsis/`

### exe 単体実行

インストール不要で実行したい場合は、`UruseeNotifier.exe` を直接配布してください。

ただし、初回起動時に Windows Defender ファイアウォールの警告が表示される場合があります。
その場合は、UDP ポート 5555 の通信を許可してください。

## 使い方

### 基本操作

1. **起動**: `UruseeNotifier.exe` をダブルクリック
2. **送信**: メインウィンドウの「うるせぇ！を送信」ボタンをクリック
3. **設定**: 「設定」ボタンをクリックして設定パネルを表示
4. **終了**: ウィンドウを閉じる

### 設定パネル

- **接続状態**: オンライン/オフライン、ブロードキャストアドレス、マシン ID を表示
- **効果音**: ON/OFF を切り替え
- **今日の送信数**: 本日の送信回数を表示

### ネットワーク設定

アプリは自動的にブロードキャストアドレスを検出します。

- **サブネット**: 192.168.x.0/24 を想定
- **ブロードキャスト**: 192.168.x.255

異なるサブネットマスクを使用する場合は、ソースコードの修正が必要です。

## ファイアウォール設定

### Windows Defender ファイアウォール

初回起動時に、UDP ポート 5555 の通信を許可してください。

手動で設定する場合：

1. Windows Defender ファイアウォールを開く
2. 「受信の規則」→「新しい規則」
3. **ポート** → **UDP** → **特定のローカルポート: 5555**
4. **接続を許可する** → プライベートとパブリックの両方にチェック

## トラブルシューティング

### 受信できない場合

1. ファイアウォールで UDP ポート 5555 が許可されているか確認
2. 同じサブネット（192.168.x.x）に接続されているか確認
3. 設定パネルでブロードキャストアドレスを確認

### 音が出ない場合

1. 設定パネルで効果音が有効になっているか確認
2. Windows の音量設定を確認
3. ブラウザの音声出力が有効か確認
