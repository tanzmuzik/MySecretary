# 🔥 UruseeNotifier

ローカルネットワーク内で「うるせぇ！」を送信し合う、タスクトレイ常駐型Electronアプリです。

## ⚡ すぐに使いたい方へ（ビルド済みEXE）

**何もインストールせずにすぐ使える！**

1. GitHubのActionsページにアクセス: https://github.com/tanzmuzik/MySecretary/actions
2. 最新の "Build Windows EXE" ワークフロー（✅緑チェック付き）をクリック
3. 下部の "Artifacts" から **UruseeNotifier-Windows** をダウンロード
4. 解凍して `UruseeNotifier Setup 1.0.0.exe` を実行

詳しくは [`EXE_DOWNLOAD.md`](EXE_DOWNLOAD.md) を参照してください。

## 📋 概要

UruseeNotifierは、同じネットワーク内のユーザー同士で匿名で「うるせぇ！」というメッセージを送信できるシンプルなアプリケーションです。タスクトレイに常駐し、ワンクリックでメッセージを送信できます。

## ✨ 主な機能

- 🖱️ **ワンクリック送信**: タスクトレイアイコンをクリックするだけで「うるせぇ！」を送信
- 💬 **ランダム表示**: 受信したメッセージは画面のランダムな位置に吹き出しで表示
- 🔔 **効果音**: カスタマイズ可能な通知音
- 📊 **ログ機能**: 送受信の履歴を記録・表示
- 🎨 **カスタマイズ**: 表示スタイルや音量を設定可能
- 🔒 **完全匿名**: 送信者の情報は一切含まれません

## 🛠️ 技術スタック

- **Electron**: デスクトップアプリケーションフレームワーク
- **React**: UIライブラリ
- **TypeScript**: 型安全な開発
- **WebSocket**: リアルタイム通信
- **Webpack**: バンドラー

## 📦 インストール

### 必要な環境

- Node.js 16.x以上
- npm または yarn

### セットアップ手順

1. リポジトリをクローン

```bash
cd UruseeNotifier
```

2. 依存関係をインストール

```bash
npm install
```

3. アセットファイルを準備

`assets/icon.png`（アプリアイコン）と`assets/sounds/paan.mp3`（効果音）を配置してください。
詳細は `assets/README_ASSETS.md` を参照してください。

## 🚀 使用方法

### 開発モード

```bash
npm run dev
```

### 本番ビルド

```bash
npm run build
npm start
```

### Windowsアプリとしてパッケージ化

```bash
npm run build:win
```

実行ファイルは `dist/` ディレクトリに生成されます。

## 📖 使い方

1. **起動**: アプリを起動すると、タスクトレイにアイコンが表示されます
2. **送信**: タスクトレイアイコンを左クリック、または設定画面から「うるせぇ！」を送信
3. **受信**: 他のユーザーからメッセージを受信すると、画面に吹き出しが表示されます
4. **設定**: タスクトレイアイコンを右クリック → 「設定」で各種設定を変更
5. **ログ**: タスクトレイアイコンを右クリック → 「ログ」で送受信履歴を確認

## ⚙️ 設定項目

### 効果音設定
- **効果音ON/OFF**: 通知音の有効/無効を切り替え
- **音量調整**: スライダーで音量を調整（0〜100%）

### 表示設定
- **表示バリエーション**: 吹き出しのスタイルを選択
  - デフォルト
  - かわいい
  - 激怒
  - クール

### ログ設定
- **今日のログ**: 本日の送受信履歴を表示
- **全てのログ**: 過去の全履歴を表示
- **エクスポート**: ログをJSONファイルとしてエクスポート
- **クリア**: 全ログを削除

## 🌐 ネットワーク設定

デフォルトでは `localhost:5555` でWebSocketサーバーが起動します。

### 同じネットワーク内の他のPCと接続する場合

1. サーバー側PCのIPアドレスを確認
2. `src/utils/websocket.ts` の接続URLを変更

```typescript
constructor(private url: string = 'ws://[サーバーのIPアドレス]:5555') {}
```

3. ファイアウォールでポート5555を許可

## 🔒 セキュリティとプライバシー

- 送信者の情報は一切含まれません（完全匿名）
- ローカルネットワーク内でのみ動作します
- ログはローカルストレージに保存されます

## 🐛 トラブルシューティング

### アプリが起動しない

- Node.jsのバージョンを確認してください（16.x以上）
- 依存関係を再インストールしてください: `npm install`

### WebSocketに接続できない

- ポート5555が使用中でないか確認してください
- ファイアウォール設定を確認してください

### 通知が表示されない

- アセットファイル（アイコン、効果音）が正しく配置されているか確認してください
- 設定で効果音が有効になっているか確認してください

### ビルドエラー

- `npm run build` を実行する前に、TypeScriptのコンパイルエラーを確認してください
- `node_modules` を削除して再インストールを試してください
