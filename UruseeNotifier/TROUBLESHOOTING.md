# トラブルシューティングガイド

## アプリが起動しない場合

最新版では、エラーが発生した場合に自動的にエラーダイアログが表示されます。

### 初回起動時

アプリが正常に起動すると、以下のダイアログが表示されます：

```
起動しました！
タスクトレイのアイコンを右クリックして設定を開いてください。

（このメッセージは初回起動時のみ表示されます）
```

このダイアログが表示されれば、アプリは正常に動作しています。

### エラーログの確認方法

エラーが発生した場合、以下の場所にログファイルが作成されます：

**Windows:**
```
C:\Users\<ユーザー名>\AppData\Roaming\urusee-notifier\error.log
```

このファイルをテキストエディタで開くと、詳細なエラー情報が確認できます。

### エラーログの場所を開く方法

1. Windowsキー + R を押す
2. `%APPDATA%\urusee-notifier` と入力してEnter
3. `error.log` ファイルを探す

### よくあるエラーと対処法

#### 1. トレイアイコンが表示されない

**エラーメッセージ:**
```
Icon is empty! Cannot create tray without an icon.
```

**対処法:**
- アプリを完全にアンインストール
- 最新版を再ダウンロード
- 再インストール

#### 2. 設定ウィンドウが開かない

**エラーメッセージ:**
```
UIファイルが見つかりません
```

**対処法:**
- アプリケーションファイルが正しくビルドされていない可能性
- 最新のビルドを再ダウンロード

#### 3. WebSocketサーバーが起動しない

**エラーメッセージ:**
```
WebSocketサーバーの起動に失敗しました
```

**対処法:**
- ポート5555が他のアプリケーションで使用されていないか確認
- ファイアウォールの設定を確認
- アプリを再起動

## デバッグモード

より詳細な情報が必要な場合は、以下の方法でデバッグモードで起動できます：

1. コマンドプロンプトを開く
2. アプリのインストール場所に移動
3. 以下のコマンドを実行：

```cmd
UruseeNotifier.exe --debug
```

デバッグモードでは、起動時に詳細な情報が表示されます。

## サポート

問題が解決しない場合は、`error.log` ファイルの内容を確認してください。
ログファイルには、エラーの詳細情報とタイムスタンプが記録されています。
