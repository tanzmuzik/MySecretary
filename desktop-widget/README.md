# デスクトップウィジェット

Windows 11対応の統合デスクトップウィジェット - 時計、カレンダー、アラーム機能を搭載

## 機能

### 🕐 アナログ時計
- 滑らかな秒針の動き
- デジタル時刻表示
- ガラスモーフィズムデザイン

### 📅 カレンダー
- 月曜日始まり
- 今日の日付をハイライト表示
- 日本の祝日表示（2024-2026年）
- 月送り/戻しボタン

### ⏰ アラーム
- 複数のアラーム設定可能
- 時刻指定
- ラベル設定
- 曜日指定（繰り返し設定）
- アラーム通知：
  - Windowsネイティブ通知
  - ウィジェット内アラート表示
  - サウンド再生

### その他
- 透明背景
- ドラッグ移動可能
- サイズ変更可能
- 常に最前面表示
- タスクバーに表示されない
- テーマ切り替え（T キーまたは右クリック）

## インストール

```bash
npm install
```

## 使い方

### 開発モード
```bash
npm start
```

### デバッグモード（コンソール出力付き）
```bash
npm run dev
```

### exeファイルをビルド
```bash
npm run build
```

ビルドされたexeファイルは `dist` フォルダに生成されます。

## アラームの設定方法

1. 「+」ボタンをクリック
2. 時刻を入力（時：0-23、分：0-59）
3. ラベルを入力（任意）
4. 繰り返す曜日を選択（任意、選択しない場合は1回のみ）
5. 「保存」をクリック

### アラームの管理
- **ON/OFF切り替え**: アラーム一覧の「ON」「OFF」ボタンをクリック
- **削除**: 「削除」ボタンをクリック

## ショートカットキー

- `T` キー または 右クリック: ライトテーマ/ダークテーマ切り替え
