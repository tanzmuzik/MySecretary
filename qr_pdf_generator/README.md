# QRコード配置 PDF 生成アプリ（Windows 版）

マンション入居者向けテンプレートPDFに、QRコード画像と部屋番号を自動配置して、複数のPDFを出力するアプリケーションです。

**対応環境：Windows 10/11**

## 仕様

### GUI画面（初期化面）
- **テンプレートPDFのパス指定**：ファイル選択ダイアログ
- **QRコード画像フォルダの指定**：フォルダ選択ダイアログ（自動検出）
- **出力フォルダの指定**：ファイル選択ダイアログ
- **「実行」ボタン**：処理を実行

### 自動検出機能
- フォルダ内の `qr_*.png` ファイルを自動検出
- ファイル名から部屋番号を自動抽出（`qr_101.png` → `101`）
- ナンバリング規則に依存しない（101, 102... A201, A202... など対応）

### 処理ロジック

#### スロット配置
テンプレートPDFは、以下の配置で10個のスロット（四角い枠）があります：
- **行数**：2行
- **列数**：5列
- **合計**：10スロット

#### スロット座標（A4用紙基準）
| スロット位置 | X座標（mm） | Y座標（mm） |
|-----------|-----------|-----------|
| 1行目 1～5 | 20, 70, 120, 170, 220 | 240 |
| 2行目 1～5 | 20, 70, 120, 170, 220 | 170 |

#### 処理フロー
1. 指定フォルダから `qr_{部屋番号}.png` 形式の画像を読み込む
2. テンプレートPDFに QR画像を配置
3. 各画像の下に部屋番号をテキストで追記（フォント：12pt）
4. 10個ごとに1PDFを分割して出力

### 出力

複数のPDFファイルを自動生成します：
- **ファイル名**：`output_1.pdf`, `output_2.pdf`, ...
- **出力先**：指定された出力フォルダに自動保存

## 技術スタック

- **言語**：Python 3.10 以上
- **GUI**：tkinter（Python標準ライブラリ）
- **PDF操作**：PyPDF2
- **画像処理**：Pillow
- **テキスト追記**：reportlab
- **日本語フォント**：Windows標準フォント（Yu Gothic、Meiryoなど）

3. **インストール完了**

## 使用方法

### 方法1：実行スクリプトを使う（推奨）

### 使用例

1. **アプリを起動**
   ```cmd
   run.bat
   ```

2. **テンプレートPDFを選択**
   - 「参照...」ボタンをクリック
   - `割付印刷用.pdf` を選択

3. **QRコードフォルダを選択**
   - 「参照...」ボタンをクリック
   - `qr_images` フォルダを選択
   - ⚠️ **重要**：フォルダ内のファイル名は必ず `qr_*.png` 形式
     - 例：`qr_101.png`, `qr_102.png`, `qr_A201.png`, `qr_A202.png` など
     - ナンバリング規則は自由（101～136、A101～A210 など）

4. **出力フォルダを指定**
   - 「参照...」ボタンをクリック
   - 出力フォルダを選択

5. **「実行」ボタンをクリック**
   - フォルダ内のQRコード画像を自動検出
   - 部屋番号を自動抽出
   - 処理が開始
   - 自動で以下のPDFが生成される（例）：
     - `output_1.pdf`（10室分）
     - `output_2.pdf`（10室分）
     - `output_3.pdf`（10室分）
     - `output_4.pdf`（6室分）

## API リファレンス

### PDFProcessor クラス

#### `__init__(template_pdf_path: str)`
PDF処理の初期化

**パラメータ：**
- `template_pdf_path`: テンプレートPDFのパス

**例外：**
- `FileNotFoundError`: テンプレートPDFが見つからない
- `ValueError`: ファイル形式が不正

#### `create_output_pdf(qr_images: List[str], room_numbers: List[str], output_path: str)`
QRコードと部屋番号をテンプレートPDFに配置して出力

**パラメータ：**
- `qr_images`: QRコード画像ファイルパスのリスト
- `room_numbers`: 部屋番号のリスト（文字列）
- `output_path`: 出力PDFのパス

**例外：**
- `ValueError`: QR画像と部屋番号の数が不一致、または10を超える場合

### ヘルパー関数

#### `split_rooms_into_batches(start_room: int, end_room: int, batch_size: int = 10)`
部屋番号をバッチに分割

**パラメータ：**
- `start_room`: 開始部屋番号
- `end_room`: 終了部屋番号
- `batch_size`: バッチあたりの件数（デフォルト：10）

**戻り値：**
`(開始番号, 終了番号)` のタプルリスト

## エラーハンドリング

アプリケーションは以下のエラーに対応しています：

- **FileNotFoundError**：QRコード画像ファイルが見つからない
- **ValueError**：
  - 開始番号 > 終了番号
  - 部屋数が1000を超える
  - 部屋番号が数値ではない
  - QR画像と部屋番号の数が不一致
- **その他の予期しないエラー**：詳細なエラーメッセージをダイアログに表示

## トラブルシューティング

### Q1：setup.bat 実行時に「Pythonが見つかりません」エラー

**原因**：Python がインストールされていない、または PATH に追加されていない

**対応**：
1. [python.org](https://www.python.org/downloads/) から Python 3.10 以上をダウンロード
2. インストール時に **「Add Python to PATH」にチェック** を入れる
3. セットアップを再実行

### Q2：run.bat を実行しても何も起こらない

**原因**：仮想環境が正常に作成されていない

**対応**：
1. コマンドプロンプトを開く
2. プロジェクトディレクトリに移動
3. 以下を実行：
   ```cmd
   setup.bat
   ```

### Q3：「QR code image not found」エラーが出る

**原因**：QRコード画像ファイルがフォルダに存在しない

**対応**：
- ファイル名が正確に `qr_101.png` 形式になっているか確認
- ファイルフォーマット（PNG）が正しいか確認
- 部屋番号が実際のファイルと一致しているか確認
- 大文字・小文字が一致しているか確認

### Q4：PDF の座標がズレている

**原因**：テンプレートPDFのページサイズやスロット位置が異なる

**対応**：
1. テンプレートPDFをスクリーンショットで撮影
2. 実際のスロット位置の座標を測定
3. `src/pdf_processor.py` の `SlotCoordinate.SLOTS` を調整
   ```python
   SLOTS = [
       {"row": 1, "col": 1, "x": 20, "y": 240, ...},  # X, Y を調整
   ```

### Q5：テキストが PDF に表示されない

**原因**：日本語フォントが正しく登録されていない

**対応**：
- Windows 標準の日本語フォント（Yu Gothic、Meiryo など）は通常インストール済み
- Windows Fonts フォルダ（`C:\Windows\Fonts`）に日本語フォントがあるか確認
- 不足している場合は Windows 設定から言語パックをインストール

## セキュリティ

- **個人情報保護**：QRコードはローカル環境で処理され、外部に送信されることはありません
- **ローカル実行のみ**：サーバーアップロード機能は実装されていません

## パフォーマンス

- 通常、部屋100室分のPDF生成は数秒で完了します
- スロット数が10個を超える場合は複数ファイルに自動分割されます

## よくある質問

**Q: MacBook でも使えますか？**
A: 現在、Windows 専用です。macOS 版の開発予定はありません。

**Q: 既存のpython環境を使いたいです**
A: 以下を実行してパッケージをインストールしてください：
```cmd

```

**Q: スロット座標をカスタマイズできますか？**
A: はい。`src/pdf_processor.py` の `SlotCoordinate.SLOTS` を編集してください。
