# QRコード配置 PDF 生成アプリ（ローカル実行版）

マンション入居者向けテンプレートPDFに、QRコード画像と部屋番号を自動配置して、複数のPDFを出力するアプリケーションです。

## 仕様

### GUI画面（初期化面）
- **テンプレートPDFのパス指定**：ファイル選択ダイアログ
- **QRコード画像フォルダの指定**：フォルダ選択ダイアログ
- **部屋番号の指定**：開始番号・終了番号を入力フィールドで指定（例：101～136）
- **出力フォルダの指定**：ファイル選択ダイアログ
- **「実行」ボタン**：処理を実行

### 処理ロジック

#### スロット配置
テンプレートPDFは、以下の配置で10個のスロット（四角い枠）があります：
- **行数**：2行
- **列数**：5列
- **合計**：10スロット

#### スロット座標（A4用紙基準）
| スロット位置 | X座標（mm） | Y座標（mm） |
|-----------|-----------|-----------|
| 1行目 1～5 | 20, 70, 120, 170, 220 | 240 |
| 2行目 1～5 | 20, 70, 120, 170, 220 | 170 |

#### 処理フロー
1. 指定フォルダから `qr_{部屋番号}.png` 形式の画像を読み込む
2. テンプレートPDFに QR画像を配置
3. 各画像の下に部屋番号をテキストで追記（フォント：12pt、日本語対応）
4. 10個ごとに1PDFを分割して出力

### 出力

複数のPDFファイルを自動生成します：
- **ファイル名**：`output_1.pdf`, `output_2.pdf`, ...
- **出力先**：指定された出力フォルダに自動保存

## 技術スタック

- **言語**：Python 3.12
- **GUI**：tkinter（標準ライブラリ）
- **PDF操作**：PyPDF2
- **画像処理**：Pillow
- **テキスト追記**：reportlab
- **日本語フォント**：システムフォント対応

## 使用例

### ユーザーの操作フロー

1. **アプリを起動**
   ```bash
   python src/main.py
   ```

2. **テンプレートPDFを選択**
   - 「参照...」ボタンをクリック
   - `割付印刷用.pdf` を選択

3. **QRコードフォルダを選択**
   - 「参照...」ボタンをクリック
   - `qr_images` フォルダを選択
   - フォルダには以下のファイルが入っていることを想定：
     - `qr_101.png`, `qr_102.png`, ..., `qr_136.png`

4. **部屋番号を入力**
   - 開始番号：`101`
   - 終了番号：`136`

5. **出力フォルダを指定**
   - 「参照...」ボタンをクリック
   - 出力フォルダを選択

6. **「実行」ボタンをクリック**
   - 処理が開始
   - 自動で以下のPDFが生成される：
     - `output_1.pdf`（QRコード 101～110）
     - `output_2.pdf`（QRコード 111～120）
     - `output_3.pdf`（QRコード 121～130）
     - `output_4.pdf`（QRコード 131～136）

## API リファレンス

### PDFProcessor クラス

#### `__init__(template_pdf_path: str)`
PDF処理の初期化

**パラメータ：**
- `template_pdf_path`: テンプレートPDFのパス

**例外：**
- `FileNotFoundError`: テンプレートPDFが見つからない
- `ValueError`: ファイル形式が不正

#### `create_output_pdf(qr_images: List[str], room_numbers: List[str], output_path: str)`
QRコードと部屋番号をテンプレートPDFに配置して出力

**パラメータ：**
- `qr_images`: QRコード画像ファイルパスのリスト
- `room_numbers`: 部屋番号のリスト（文字列）
- `output_path`: 出力PDFのパス

**例外：**
- `ValueError`: QR画像と部屋番号の数が不一致、または10を超える場合

### ヘルパー関数

#### `split_rooms_into_batches(start_room: int, end_room: int, batch_size: int = 10)`
部屋番号をバッチに分割

**パラメータ：**
- `start_room`: 開始部屋番号
- `end_room`: 終了部屋番号
- `batch_size`: バッチあたりの件数（デフォルト：10）

**戻り値：**
`(開始番号, 終了番号)` のタプルリスト

## エラーハンドリング

アプリケーションは以下のエラーに対応しています：

- **FileNotFoundError**：QRコード画像ファイルが見つからない
- **ValueError**：
  - 開始番号 > 終了番号
  - 部屋数が1000を超える
  - 部屋番号が数値ではない
- **その他の予期しないエラー**：詳細なエラーメッセージをダイアログに表示

## 注意点

### セキュリティ
- **個人情報保護**：QRコードはローカル環境で処理され、外部に送信されることはありません
- **ローカル実行のみ**：サーバーアップロード機能は実装されていません

### 動作環境
- **対応OS**：macOS, Linux, Windows
- **Python バージョン**：3.12以上推奨
- **必須フォント**：日本語フォント（通常、OSに含まれている）

### パフォーマンス
- 通常、部屋100室分のPDF生成は数秒で完了します
- スロット数が10個を超える場合は複数ファイルに自動分割されます

## トラブルシューティング

### Q1：「QR code image not found」エラーが出る

**原因**：QRコード画像ファイルがフォルダに存在しない

**対応**：
- ファイル名が正確に `qr_101.png` 形式になっているか確認
- ファイルフォーマット（PNG）が正しいか確認
- 部屋番号が実際のファイルと一致しているか確認

### Q2：テキストが PDF に表示されない

**原因**：日本語フォントが見つからない

**対応**：
- Linux/Windows：日本語フォントをインストール
- Mac：通常、標準日本語フォントが含まれています

### Q3：PDF の座標がズレている

**原因**：テンプレートPDFのページサイズが異なる

**対応**：
- `pdf_processor.py` の `SlotCoordinate.SLOTS` を調整してください
- テンプレートPDFの実際の座標を確認して修正してください
